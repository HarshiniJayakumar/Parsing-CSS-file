# Parsing-CSS-file

1.This project is a simple CSS Parser developed using Python.

2.It reads and analyzes CSS files.

3.It extracts CSS selectors from the file.

4.It identifies CSS properties and their values.

5.It organizes the extracted information into a structured format.

6.It helps users understand the contents of a CSS file.

7.It identifies duplicate properties where supported.

8.It handles parsing errors and malformed CSS.
